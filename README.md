# Delicias Loli

## Sobre el proyecto

Delicias Loli es una tienda online para mostrar y vender productos de repostería casera y ademas personalizar eventos y mesas. Este repositorio contiene el código fuente del proyecto.

## Demo

El proyecto está desplegado en Vercel:

[delicias-loli-j7k1xytt3-neiraeliana2406-4224.vercel.app](https://delicias-loli-j7k1xytt3-neiraeliana2406-4224.vercel.app)

## Características
Catálogo de productos con fotos y precios
Carrito de compras / pedidos por WhatsApp
Información de contacto y ubicación
Diseño adaptable a celulares
